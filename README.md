# 🤖 Quiz Bot - Telegram

Bot de Telegram para crear y gestionar cuestionarios con preguntas de opción múltiple, verdadero/falso y respuestas abiertas.

## 📌 Características

- ✅ **Un único administrador** con panel completo de control
- ✅ **Tres tipos de preguntas**: Múltiple, Verdadero/Falso y Abierta
- ✅ **Adjuntos por pregunta**: Imágenes, videos y enlaces
- ✅ **Tiempo por pregunta** o tiempo global configurable
- ✅ **Selección de preguntas**: Fijas, al azar o por filtro
- ✅ **Hasta 5000 preguntas** y mostrar 100 aleatorias
- ✅ **Historial completo**: Guarda absolutamente todo
- ✅ **Notificaciones al admin** cuando alguien termina
- ✅ **Reintentos configurados** por el admin
- ✅ **Subida masiva por CSV** con archivo de ejemplo descargable
- ✅ **Respaldos locales** si falla Supabase
- ✅ **Compresión de imágenes** automática
- ✅ **Despliegue gratuito** en Render + cron-job.org

## 🛠️ Tecnologías

- **Python 3.10+**
- **python-telegram-bot** (v20.7)
- **Supabase** (PostgreSQL + Storage)
- **Render** (Hosting gratuito)
- **cron-job.org** (Mantener vivo)
